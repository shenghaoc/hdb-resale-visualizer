# Data sources and licence

HDB Resale Explorer is built from official open data. This page names every dataset, who publishes it and the licence it is used under. A short credit with a link to the licence stays on screen whenever the map does.

## Notice

Contains information from the datasets listed below, accessed on the date shown as **Synced** in the header of the app, from [data.gov.sg](https://data.gov.sg), which is made available under the terms of the [Singapore Open Data Licence version 1.0](https://data.gov.sg/open-data-licence).

Map tiles, addresses and walking times use [OneMap](https://www.onemap.gov.sg/home), © OneMap contributors, Singapore Land Authority.

## When the data was accessed

The data in the app is a snapshot taken when it was last synced, not a live feed. The header shows the latest transaction month and the sync time; treat those as the access date of the datasets above.

## No official status

HDB Resale Explorer is an independent tool. It has no official status, and none of the agencies above endorses it or its use of their datasets. The comparisons, medians, trends and caveats it shows are its own calculations over the published data, not the agencies' figures.

## The licence

The Singapore Open Data Licence applies to the datasets, not to this application. Read the full, current text at [data.gov.sg/open-data-licence](https://data.gov.sg/open-data-licence).
